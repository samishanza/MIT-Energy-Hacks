# National Grid tariff No. 1632 compared with No. 1468

Date: 2026-11-07. A team member downloaded M.D.P.U. No. 1632 in a browser, because mass.gov blocks automated reads. It cancels No. 1620, was issued February 25, 2026, and took effect May 1, 2026. The file's name says stamp-approved April 27, 2026. It's the newest version we've seen, and we haven't checked whether a later one exists.

**Method:** text extracted from both PDFs and compared word by word, after removing page headers and form underlines. The rule sections were 98% the same. Tables don't extract cleanly, so the review timeline tables weren't reliably compared. The rules below were also read directly.

## What the readiness table relies on

| Rule | No. 1468 | No. 1632 |
|---|---|---|
| Pre-Application Report | Required at 250 kW or more, optional below | Same |
| Report fee | $100 below 250 kW, $250 for 250 to 500 kW, $750 above 500 kW | Same |
| Time to issue the report | 10 business days | Same |
| Contents of the report | 16 items | Same 16 items |
| Acknowledgment of an application | 3 business days | Same |
| Completeness notice | 10 business days, saying what's missing if incomplete | Same |
| Account number and meter number on the form | Yes | Yes |
| Field for service size or switchgear rating | None | None |
| One-line diagram | Massachusetts PE stamp, Sheet 117 | Massachusetts PE stamp, Page 124 |
| Site control | Attachment 1A or 1B | Same |

## What changed

**Exhibit C has one new block, on Page 117.** It asks whether the application is for a new Facility or a change to an existing one. For a change, it asks for the existing application number, a description of the change, existing nameplate capacity, the proposed change in capacity, and total capacity. Exhibit A has the same block.

**In the rule sections:**

- **Expansions:** expanding a Facility that has an executed Interconnection Service Agreement now requires an amendment, not a new agreement.
- **Group studies:** Expedited Process projects may be exempt from a Group Study if they pass all initial screens and need no material system modifications or further engineering study.
- **Simplified Process:** eligibility now points to criteria in Section 3.1.
- **Smaller changes:** capital investment project payment schedules, a possible higher limit on one generator rating, and a mention of Common System Modifications.

**Exhibit B** differs only in contact fields.
